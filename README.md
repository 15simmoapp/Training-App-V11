# Matthew's Training App V11

V11 adds an 11-minute Tai Chi-inspired morning mobility flow alongside gym training, speed bag and calisthenics side quests.

## Mobility sequence
1. Lymphatic Hops
2. Body Waves
3. Arm Swings
4. Trunk Twists
5. Dead Arms
6. Golf Swings
7. Knee Taps
8. Toe Touches
9. Side Lunges
10. Plie Squats
11. Fascia Slaps

Each movement runs for 60 seconds. The flow supports pause, back, skip, automatic movement changes, vibration and completion history.

## Deployment
Upload all contents to a GitHub repository root and enable Pages from `main` and `/(root)`.
